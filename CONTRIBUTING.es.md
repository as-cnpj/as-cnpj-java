# Contribuir

Este paquete sigue la gobernanza del ecosistema AS-CNPJ.

Reglas base:

- no copiar codigo de terceros;
- mantener el contrato alineado con los vectores compartidos del hub;
- evitar dependencias innecesarias en el nucleo;
- preservar consistencia de API entre lenguajes.

Contacto institucional: `ascnpj@0moura.io`
