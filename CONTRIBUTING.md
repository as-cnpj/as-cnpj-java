# Contribuindo

Este pacote segue a governanca do ecossistema AS-CNPJ.

Diretrizes basicas:

- nao copiar codigo de terceiros;
- manter o contrato alinhado aos vetores compartilhados do hub;
- evitar dependencias desnecessarias no nucleo;
- preservar previsibilidade de API entre linguagens.

Contato institucional: `ascnpj@0moura.io`
